## User-approved product direction
- One usable application/workflow: reuse **MyCut's real timeline and renderer**, not build a second competing AI Video timeline.
- Workflow: enter/paste novel screenplay in AI Video → parse narrator/dialogue/speakers → generate/reuse per-line ElevenLabs MP3 only after explicit approval of paid credits → place MP3 sequentially on MyCut A1 → user provides master-frame images/videos → propose intelligent scene/image matching and duration alignment → show preview and ask permission → user manually polishes and exports MP4.
- **Audio A1**: 0.3 seconds SILENCE **between voice lines only** by default. A2 background music and A3 effects are independent.
- **Visual V1**: fully CONTINUOUS without gaps/black screen **even during voice pauses**. A still may extend over silence or cuts may occur at deliberate voice boundaries. No zero-length/overlapping image clips.
- Respect locked clips and manually edited projects. No auto-overwrite; Save As new .mycut; never move locked shots without explicit user consent.
- Do not silently charge ElevenLabs or other APIs; get user approval for billable Vision/TTS calls. No need to display fractional-cent costs routinely, but billing approval remains essential.
- Explicit user confirmation before AI editing or applying suggested shot arrangements.

## Image sidecar description format (not AI Vision)
For `shot-001.png`, optionally add UTF-8 `shot-001.png.txt` in the same folder:
```text
บรรทัด: 3
อวิ๋นเซิงเดินเข้าป่าไผ่ในยามค่ำคืน
```
or `line: 3`. Matching uses local filename/sidecar keywords and explicit position cues. It does NOT inspect pixels, recognize characters, or call a Vision API. An unclear image retains its original position. Some Thai continuous phrases tokenize poorly.

## Critical distinctions / limitations
- Current checked-in feature outputs a **new project file** .mycut; user imports/opens in standalone MyCut. It does not automatically control MyCut UI or import media into an existing project.
- Simple image duration assignment / timing cues are NOT AI semantic storyboard matching; existing review is an Electron dialog, not a full visual shot-by-shot editing UI.
- No actual image visual understanding model integrated at the baseline. If implementing Vision, add an explicit provider/config, preview of what leaves the PC, credit/cost confirmation, permission gating, and a no-cost fallback. Avoid implying a completed integration.
- Existing project '1019' in user's MyCut must remain untouched.

- MP3 manifest order should follow confirmed script/production plan, not random UUID or file creation order.
